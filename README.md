# Veil — Sunglasses Store

Premium static storefront for **Veil** sunglasses (black / cream / accent `#c41e3a`).

## Open locally

```bash
python3 -m http.server 8080
```

Visit http://localhost:8080

## Live

https://sunglasses-store-theta.vercel.app

## Motion features

- Loader with accent scribble + count pulse
- Custom red-dot cursor (desktop hover only) with VIEW labels
- Hero entrance + particles + subtle parallax
- Diagonal marquees (materials + cities)
- Sticky lens stack with wheel / ± transitions and price motion
- Cream “craft” accent section
- Location hover/click reveals + pulsing status dots
- Product grid stagger-in + hover overlays
- Footer scale-in + city marquee
- Smooth scroll; respects `prefers-reduced-motion`

## Files

- `index.html` — full site (HTML, CSS, JS inline)
- `vercel.json` — clean URLs
